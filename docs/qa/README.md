# QA evidence

This directory contains historical UI and browser-verification evidence for the Mitsubishi CRM prototype. These files document earlier design, responsive, role, and theme reviews; they are not application runtime assets.

Screenshots are grouped by feature area under `screenshots/`. New automated browser runs should use temporary Edge profiles outside the repository, or `.edge-*` directories that remain ignored and are removed after verification.

See [design-review.md](design-review.md) for the original design QA notes.
